# hiKing – сервис планирования экскурсий

## Назначение

hiKing – консольное приложение для планирования и бронирования экскурсий.  
Приложение позволяет:

* просматривать экскурсии;
* фильтровать экскурсии по сложности и времени прохождения;
* проверять пригодность группы для экскурсии по возрасту;
* назначать гида к группе;
* рассчитывать заработок гида за проведение экскурсии;
* разбивать группу на подгруппы, если это требуется условиями экскурсии;
* хранить данные между запусками приложения.

## Целевая аудитория

Люди от 16 до 100 лет, мужского и женского пола, любящие посещать музеи, парки, достопримечательности, а также устраивать кемпинги.

## Предметная область

Предметная область – путешествия и развлечения.

Основными объектами предметной области являются:

* экскурсия;
* маршрут;
* группа;
* гид.

Гид может быть назначен к группе.  
Группа может быть проверена на пригодность для экскурсии по возрасту участников.  
Группа может быть разбита на подгруппы, если это требуется условиями экскурсии.

## Основные сущности

### Excursion – экскурсия

Объект `Excursion` представляет экскурсию, доступную для бронирования.

Основные атрибуты:

* `excursion_id` – уникальный идентификатор экскурсии;
* `excursion_name` – название экскурсии;
* `max_persons` – максимальное количество участников;
* `min_persons` – минимальное количество участников;
* `max_age` – максимальный возраст участника;
* `min_age` – минимальный возраст участника;
* `route_length_m` – длина маршрута в метрах;
* `guide_id` – идентификатор гида.

Основные методы:

* `to_dict()` – преобразование объекта в словарь;
* `from_dict()` – создание объекта `Excursion` из словаря;
* `__str__()` – строковое представление экскурсии.

### Group – группа

Объект `Group` представляет группу участников экскурсии.

Основные атрибуты:

* `group_id` – уникальный идентификатор группы;
* `excursion_id` – идентификатор экскурсии;
* `count_of_people` – количество участников;
* `persons` – словарь участников группы.

Основные методы:

* `to_dict()` – преобразование объекта в словарь;
* `from_dict()` – создание объекта `Group` из словаря;
* `__str__()` – строковое представление группы.

### Guide – гид

Объект `Guide` представляет гида, проводящего экскурсию.

Основные атрибуты:

* `guide_id` – уникальный идентификатор гида;
* `first_name` – имя гида;
* `last_name` – фамилия гида;
* `experience` – опыт проведения экскурсий;
* `email` – адрес электронной почты.

Основные методы:

* `to_dict()` – преобразование объекта в словарь;
* `from_dict()` – создание объекта `Guide` из словаря;
* `__str__()` – строковое представление гида.

### Route – маршрут

Объект `Route` представляет маршрут экскурсии.

Основные атрибуты:

* `route_id` – уникальный идентификатор маршрута;
* `route_name` – название маршрута;
* `length_m` – длина маршрута в метрах;
* `difficulty` – сложность маршрута;
* `duration_min` – время прохождения в минутах.

Основные методы:

* `to_dict()` – преобразование объекта в словарь;
* `from_dict()` – создание объекта `Route` из словаря;
* `__str__()` – строковое представление маршрута.

## Основные операции

### Работа с экскурсиями

* добавление экскурсии;
* поиск экскурсии по названию;
* фильтрация экскурсий по сложности;
* фильтрация экскурсий по времени прохождения;
* просмотр списка экскурсий.

### Работа с группами

* создание группы;
* добавление участника в группу;
* удаление участника из группы;
* проверка пригодности группы для экскурсии по возрасту;
* разбиение группы на подгруппы.

### Работа с гидами

* создание гида;
* назначение гида к группе;
* расчёт заработка гида за проведение экскурсии с учётом количества участников;
* просмотр информации о гиде.

### Работа с маршрутами

* добавление маршрута;
* просмотр списка маршрутов;
* поиск маршрута по сложности.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

* `data/excursions.json`;
* `data/groups.json`;
* `data/guides.json`;
* `data/routes.json`.

При загрузке данные из JSON преобразуются в объекты `Excursion`, `Group`, `Guide` и `Route`.  
При сохранении объекты преобразуются в данные.

Для связи экскурсии с гидом и группой в `excursions.json` используются их идентификаторы `guide_id` и `group_id`.

## Назначение модулей

### `main.py`

Точка входа в приложение.  
Отвечает за:

* запуск приложения;
* отображение меню;
* получение данных от пользователя;
* организацию пользовательских сценариев.

### `models/excursion.py`

Содержит класс `Excursion` и функции работы с экскурсиями.

### `models/group.py`

Содержит класс `Group` и функции работы с группами.

### `models/guide.py`

Содержит класс `Guide` и функции работы с гидами.

### `models/route.py`

Содержит класс `Route` и функции работы с маршрутами.

### `services.py`

Содержит сервисы `ExcursionService`, `GroupService`, `GuideService` и `RouteService`, отвечающие за бизнес-логику приложения.

### `storage.py`

Отвечает за загрузку и сохранение данных.  
Выполняет преобразования:

* JSON → объекты Python;
* объекты Python → JSON.

### `console_app.py`

Содержит классы консольного интерфейса:

* `ConsoleUtils` – вспомогательные методы ввода-вывода;
* `ExcursionConsole` – меню работы с экскурсиями;
* `GroupConsole` – меню работы с группами;
* `GuideConsole` – меню работы с гидами;
* `RouteConsole` – меню работы с маршрутами.

### `tests/`

Содержит автоматизированные тесты проекта.

## Запуск приложения

Для запуска приложения выполнить:

* создание и удаление групп;
* назначение гида к группе;

* расчёт заработка гида;
