# Название проекта
Сервис планирования экскурсий
## Назначение
Сервис позволяющий людям записаться на экскурсию, посмотреть условия, также отфильтровать по сложности, времени прохождения, а также гиду получить доступ к тому чтобы записаться на экскурсию и получить оплату, а также люди должны видеть отзывы.
## Целевая аудитория
Люди от 16 до 100 лет, мужского и женского пола, любящие посещать музеи, парки, достопримечательности, а также устраивать кемпинги. 
## Предметная область
Предметная область - путеществия и развлечения, 
## Основные сущности
- Экскурсия
- Маршрут
- Группа
- Гид
## Основные функции
- Назначение гида к группе
- Проверка пригодности группы для экскурсии по возрасту 
- Рассчет заработка гида за проведение экскурсии, с учетом количества участников
- разбиение группы на подгруппы, при требовании этого в экскурсии 
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
